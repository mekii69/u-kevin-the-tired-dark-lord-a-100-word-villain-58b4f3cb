A deterministic program that writes one original 100-word fantasy-villain monologue to `/output/entry.txt`: a fixed string in `main.py` — no network, no input, no randomness. The villain's exhaustion is felt in pauses, deflections, and paperwork, never announced; he has a mountain, a three-century eclipse scheme, and a hero whose father gave the same speech before.

## Run it

```sh
python3 main.py
```
